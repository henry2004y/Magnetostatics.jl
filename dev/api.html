julia
solve(solver::FFTSolver{OpenBoundary}, J, dx)

Open-boundary (free-space) solver using Hockney's discrete Green's function convolution method. The current density J is zero-padded to twice the size in each dimension and convolved with the isolated 3D Green's function G(r) = 1/(4π r), eliminating periodic wrap-around artifacts.

Magnetostatics.FLARECoils Type
julia
FLARECoils{T} <: AbstractMagneticField

Magnetic field configuration of the Facility for Laboratory Reconnection Experiments (FLARE) at Princeton University / PPPL.

FLARE scales up the cylindrical flux-core reconnection concept pioneered by MRX:

  • Two internal flux cores at radius R_pf and locations z = ±z_pf, housing Poloidal Field (PF) coils.

  • External Equilibrium Field (EF) coils at radius R_ef and z = ±z_ef to control the radial position of the current sheet.

  • Optional midplane plasma current I_p at radius R_p representing the inductive reconnection layer.

  • Optional out-of-plane (toroidal) guide field B_guide.

Fields

  • R_pf::T: Flux core major radius [m] (nominal: 0.75 m).

  • z_pf::T: Flux core axial half-separation [m] (nominal: 0.40 m).

  • I_pf::T: Current in each PF coil [A].

  • R_ef::T: Radius of external EF coils [m] (nominal: 1.30 m).

  • z_ef::T: Axial half-separation of external EF coils [m] (nominal: 0.70 m).

  • I_ef::T: Current in each EF coil [A].

  • R_p::T: Reconnection layer plasma major radius [m] (nominal: 0.75 m).

  • I_p::T: Induced plasma current in the current sheet [A].

  • B_guide::T: Toroidal guide field at R_p [T].

source
Magnetostatics.ParkerSpiral Type
julia
ParkerSpiral{T} <: AbstractMagneticField

Parker spiral model of the heliospheric magnetic field (IMF) in the solar wind:

  • Br(r, θ) = B0 * (r0 / r)^2

  • Bϕ(r, θ) = -B0 * (r0 / r)^2 * (Ω * (r - r0) / v_sw) * sin(θ)

  • Bθ = 0

Fields

  • B0::T: Reference radial magnetic field strength at radius r0 [T].

  • r0::T: Reference radius [m] (e.g. 1 AU = 1.496e11 m or 1 R_sun = 6.96e8 m).

  • v_sw::T: Solar wind radial velocity [m/s] (default: 400 km/s).

  • Omega::T: Solar angular rotation speed [rad/s] (default: 2.86e-6 rad/s).

  • center::SVector{3, T}: Origin coordinates of the central star [m].

Magnetostatics.PoissonSolver Type
julia
PoissonSolver{ALG} <: AbstractSolver

Grid-based solver for the magnetostatic vector potential equation ∇²A = −μ₀ J on a uniform Cartesian grid with homogeneous Dirichlet boundary conditions (A = 0 on all domain faces).

Each Cartesian component is solved independently with the same 7-point finite-difference Laplacian matrix via LinearSolve.jl. Pass anyLinearSolve algorithm as alg; the default is KrylovJL_CG().

Fields

  • xs, ys, zs: grid node positions as AbstractRange objects.

  • alg: LinearSolve algorithm (e.g. KrylovJL_CG(), KLUFactorization(), UMFPACKFactorization()).

Example

julia
xs = range(-1.0, 1.0; length = 32)
ys = range(-1.0, 1.0; length = 32)
zs = range(-0.5, 0.5; length = 16)
solver = PoissonSolver(xs, ys, zs) # default: CG
solver_direct = PoissonSolver(xs, ys, zs; alg = KLUFactorization())
A = solve(solver, J_grid)  # J_grid :: (3,nx,ny,nz)

Inverse reconstruction ​

Axisymmetric probe fitting ​

Magnetostatics.AxisymmetricFieldReconstruction Type
julia
AxisymmetricFieldReconstruction <: AbstractMagneticField

Continuous axisymmetric magnetic field reconstructed from sparse measurements using a compactly supported Wendland C2 radial-basis expansion of the poloidal flux ψ(R, Z) by default, optionally augmented with global vacuum (homogeneous Grad–Shafranov) polynomial solutions, virtual external filaments, and softened toroidal current elements that carry net plasma current. The poloidal field is divergence-free by construction. The toroidal field is fit independently when toroidal measurements are supplied. Unlike FieldReconstruction3D, this model assumes azimuthal symmetry about the z axis and fits cylindrical probe components on an (R, Z) domain.

source
Magnetostatics.reconstruct_axisymmetric_field Function
julia
reconstruct_axisymmetric_field(positions, B_observed; domain, length_scale,
                               regularization, uncertainties, algorithm, ...)

Fit a continuous axisymmetric field to sparse magnetic-field samples. positions is an n × 2 matrix of (R, Z) coordinates and B_observed is an n × 3 matrix of cylindrical (B_R, B_ϕ, B_Z) components. Non-finite field components are treated as missing measurements. The default :wendland_c2 kernel has support radius length_scale and produces a sparse design matrix; :gaussian selects a global Gaussian basis. The default iterative algorithm is LSMR and can be customized with algorithm.

vacuum_degree = N augments the local basis with the constant and the degree 2:N polynomial solutions of Δ*ψ = 0 (current-free fields such as a uniform B_Z, quadrupole, and hexapole components, normalized by Rmax). These global terms capture the smooth field from distant coils that a compact basis alone represents poorly; the radial basis then models local currents.

filament_positions is an m × 2 matrix of (R, Z) locations, outside the domain, of virtual coaxial current filaments whose currents are fit (method of fundamental solutions). Each filament field is current-free inside the domain, so they efficiently represent fields from nearby external coils; place them between the domain and the real sources, e.g. on a curve surrounding the domain. Fitted currents are stored in filament_currents [A].

current_element_positions is an m × 2 matrix of (R, Z) locations of softened toroidal current elements whose currents are fit and stored in element_currents [A]. Each element is a coaxial loop with a smooth core of width current_element_width (default: median nearest-neighbor spacing of the elements), with current density J_ϕ ≈ (I/π) ε² / (d² + ε²)² and the vacuum loop field far away. Unlike radial basis functions, elements carry net toroidal current, so sum(field.element_currents) estimates the plasma current. Place them on a grid covering the region where plasma current may flow, with spacing comparable to the smallest current structure.

boundary_positions and boundary_flux impose exact poloidal-flux constraints. Supply boundary_uncertainties to treat them as weighted observations instead. current_positions and current_density add toroidal-current samples through the Grad–Shafranov equation, weighted by current_uncertainties in the same units as current_density (A/m²). Setting current_density to zero at collocation points imposes a vacuum prior; a loose uncertainty (comparable to the expected plasma current density) instead acts as a minimum-current regularization. Compactly supported ψ bumps carry no net toroidal current, so for fields with a distributed plasma current add current elements (or use the :gaussian kernel, whose wide tails can place return currents outside the domain). The fitted current density is available through current_density(field, pos). The domain is (Rmin, Rmax, Zmin, Zmax); evaluation outside it throws DomainError. Singular sources such as coil filaments cannot be represented and should lie outside the domain. The default current uncertainty is 1 A/m². Exact boundary constraints currently use a dense null-space reduction; pass boundary uncertainties for the scalable iterative path.

Magnetostatics.reconstruct_field_3d Function
julia
reconstruct_field_3d(positions, B_observed; domain, length_scale, ...)

Fit a divergence-free Cartesian magnetic field. positions and B_observed are n × 3 matrices. NaN field components denote missing measurements; infinite values are rejected. uncertainties has the observation shape and is in tesla. The box domain is (xmin, xmax, ymin, ymax, zmin, zmax).

The model is reference_field + b₀ + curl(A), with A = length_scale * sum(φⱼ * aⱼ). :wendland_c2 (default) has support radius length_scale; :gaussian is global. Default centers cover the box; custom basis_centers must be an m × 3 matrix inside it. reference_field defaults to NullField() and must itself be divergence-free.

Additional directional probes use directional_positions, unit directional_directions and scalar directional_values in tesla, with directional_uncertainties (default: one tesla). Cartesian or directional components marked NaN are skipped, including their uncertainty entries.

boundary_positions, unit boundary_normals and finite boundary_values constrain n ⋅ B. Without boundary_uncertainties these are exact constraints at the supplied points; otherwise they are weighted observations in tesla. The evaluation box need not coincide with this physical surface. Exact constraints use a dense null-space reduction, intended for modest problems. They do not enforce a condition between samples or establish closed-surface flux compatibility. Prefer soft constraints for noisy surface data.

current_positions and current_density are m × 3 matrices; current components and current_uncertainties (default: one A/m²) are in A/m². Current observations and current_density(field, pos) require the reference field to implement current density (zero is supported for null/uniform fields).

regularization is positive. With regularization_mode = :field (default), it penalizes the box-averaged |δB|² + length_scale² * |curl(δB)|², where δB = B - reference_field, using normalized tensor trapezoidal quadrature. The grid defaults to at least two intervals per length scale along each axis; override it with regularization_grid = (nx, ny, nz). A machine-epsilon coefficient ridge stabilizes potential gauge modes. :coefficients instead uses a coefficient ridge alone. All coefficients have field units.

Sparse least squares uses algorithm = KrylovJL_LSMR() with abstol, reltol, and maxiters (default: 10,000). Nonconvergence throws an error. field.diagnostics reports residuals in observation units, weighted RMS, exact-constraint error, convergence and sampled RBF support coverage. Uncovered locations retain only the uniform and reference fields and generate a fitting warning. Coverage on the quadrature grid is not a proof of coverage everywhere, nor are fit residuals uncertainty estimates. Sparse probes do not determine a unique physical field; basis, length scale and regularization are modeling assumptions, not additional measurements.

Spacecraft Grad-Shafranov reconstruction ​

Magnetostatics.GradShafranovReconstruction Type
julia
GradShafranovReconstruction <: AbstractMagneticField

Translationally invariant magnetohydrostatic field reconstructed from a spacecraft crossing. In its local frame, B = (A_y, -A_x, B_z(A)) and laplacian(A) = -μ₀ * dP_t/dA. This is planar spacecraft GSR, not the cylindrical flux interpolation of AxisymmetricFieldReconstruction.

Evaluate at Cartesian positions in metres; fields are returned in tesla in the input measurement frame. The finite domain applies to local x and y only. The local z coordinate is unrestricted. diagnostics describes track residuals, source-function extrapolation and the sampled GS residual, not uncertainty. The interpolated flux is C1; its analytic current is piecewise continuous in y.

source
Magnetostatics.reconstruct_grad_shafranov Function
julia
reconstruct_grad_shafranov(times, B_observed, pressure;
    crossing_velocity, invariant_axis, y, ...)

Reconstruct a planar magnetohydrostatic strip from a single straight crossing. times [s] must increase strictly; B_observed is an n × 3 Cartesian matrix [T]; pressure contains nonnegative isotropic thermal pressures [Pa]. Missing/non-finite observations are not supported.

Supply the invariant axis and constant spacecraft velocity relative to the structure, crossing_velocity = v_spacecraft - V_HT [m/s], in the measurement frame. Local x follows its projection perpendicular to the invariant axis; local y completes a right-handed frame. origin (default: zero) is the Cartesian position at the midpoint of the first and last sample times. The component of crossing velocity along the invariant axis has no effect. This function does not estimate the HT frame, axis, or equilibrium validity.

y is an increasing vector of strip coordinates [m], including zero and at least one point on each side. Trapezoidal integration gives A(x,0) = -∫B_y dx. Chebyshev least squares fits P_t(A) = pressure + B_z²/(2μ₀) and B_z(A), with pressure_degree = 3 and axial_degree = 3 by default. spatial_degree = 8 truncates the along-track Chebyshev expansion and projects the nonlinear GS source onto the same modes at every step. This is the spatial regularization, not a physical uniqueness condition.

Second-order midpoint continuation marches in both y directions, with internal steps no larger than max_step (default: half the minimum track spacing). Cubic Hermite interpolation of the flux makes field evaluation divergence-free between steps; the GS equation is satisfied only approximately. Currents use the analytic curl of this interpolated field, not the fitted source alone.

Elliptic Cauchy continuation is ill-posed. Keep a narrow strip, test smaller y steps and spatial degrees, and validate off-track when possible. A strip wider than 0.2 * track_length on either side generates a warning (a heuristic, not a stability bound). diagnostics reports field and pressure-function residuals, sampled GS residual [T/m], and the continued flux range. Polynomial source extrapolation beyond 5% of the measured flux span generates a warning; it is not an exponential-tail model or a reliable extrapolation prescription. Multi-valued pressure/axial-field data produce fit residuals, not an axis search.
