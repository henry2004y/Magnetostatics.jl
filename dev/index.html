Magnetostatics.jl ​

Magnetostatics.jl provides forward construction of magnetic fields from specified sources or potentials, and inverse reconstruction from measurements.

Start here ​

GoalStart with
Compute a field from known sources, currents, or model parametersForward methods
Reconstruct a field from spatial probes or a spacecraft crossingInverse methods
Compare axisymmetric, general 3D, and spacecraft GSR assumptionsChoosing an inverse method
Compute field geometry or guiding-center drift diagnosticsMagnetic geometry
Look up types, keyword arguments, or supported operationsAPI reference

Method guides explain assumptions, inputs, constraints, and validation. Worked examples demonstrate complete physical configurations; the API reference documents individual functions and types.

Quick Start ​

julia
using Magnetostatics
using StaticArrays

# Create a circular current loop and discretize it into wire segments
loop = CurrentLoop(1.0, 1.0, [0, 0, 0], [0, 0, 1])
wire = discretize_loop(loop, 100)

# Compute B at a point using the Biot-Savart solver
B = solve(BiotSavart(), wire, SVector(0.0, 0.0, 0.5))

# Compare with the analytical solution
B_exact = getB_loop(SVector(0.0, 0.0, 0.5), loop)

Related Packages ​

  • FieldTracer.jl: Field-line tracing for analytical and reconstructed fields through a (position, arc_length) callback, and for numerical fields through component arrays on grids. See the Parker spiral, 3D reconstruction, and FFT solver demos, which use v0.2.4 or later. UniformStreamlines.jl is retained for automatic evenly spaced streamline placement in the other visualizations. The closed-form dipole_fieldline utility is an exact geometric construction, not a numerical tracer.

  • TestParticle.jl: Charged test particle tracing and orbit dynamics (full-orbit and guiding-center pushers) in electromagnetic fields. Magnetic field models and numerical solutions from Magnetostatics.jl can be directly queried by TestParticle.jl.
