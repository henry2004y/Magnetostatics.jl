Reconstruction Across Sources and Boundaries ​

The Biot-Savart demo solves the forward problem: given sources and boundaries, compute the field. Here those configurations generate synthetic observations for the inverse problem. The reconstruction receives positions, field samples and explicitly supplied boundary/current data, not the source geometry. All fits below use the general Cartesian 3D model; see Choosing an inverse method for the distinction from axisymmetric flux reconstruction.

CaseSynthetic truthInformation given to the fit
Open loopBiot-Savart sum over 150 tilted-loop segmentsVector probes only; no artificial condition on the box faces
Conducting wallFinite wire plus its opposite-current imageVector probes and exact zero normal field at 25 wall points
Conducting sphereUniform background plus the analytic image dipoleExterior probes, known uniform background and 25 uncertain zero-normal samples on a spherical cap
Volume currentInterior of a uniform-current Z-pinchVector probes and 27 vector-current observations

The sphere uses the analytic limit from the forward demo, rather than a discretized BEM field, to avoid conflating BEM error with reconstruction error. Its box includes a small part of the sphere: probes, validation points and plots are restricted to the exterior. The fitted smooth continuation inside the sphere is not the physical interior solution. The cap is not a closed surface, and this example does not reconstruct a global multiply connected exterior.

Problems and measurements ​

julia
using Magnetostatics, StaticArrays, LinearAlgebra
using CairoMakie, Markdown

point_matrix(points) = [p[k] for p in vec(collect(points)), k in 1:3]
sample_field(field, positions) =
    point_matrix(field(SVector{3}(p)) for p in eachrow(positions))
function lattice(box, coordinates)
    return point_matrix(Iterators.product(
        ntuple(k -> [
            box[2k - 1] + t * (box[2k] - box[2k - 1]) for t in coordinates
        ], 3)...
    ))
end

box = (-0.5, 0.5, -0.5, 0.5, -0.5, 0.5)
wall_box = (-0.5, 0.5, -0.5, 0.5, 0.0, 0.6)
sphere_box = (-0.25, 0.25, -0.25, 0.25, 0.9, 1.4)
coil = discretize_loop(CurrentLoop(
    1.0, 1.0e4, SVector(0.2, -0.1, 2.0), normalize(SVector(0.3, 0.2, 1.0))
), 150)
wire = Wire([SVector(0.0, -10.0, 1.5), SVector(0.0, 10.0, 1.5)], 1.0e4)
background = UniformField(SVector(0.0, 0.0, 0.01))
image = Dipole(SVector(0.0, 0.0, -2π * 0.01 / Magnetostatics.μ₀))
pinch = ZPinch(1.0e4, 2.0)

wall_points = point_matrix(
    SVector(x, y, 0.0) for x in range(-0.4, 0.4; length = 5),
        y in range(-0.4, 0.4; length = 5)
)
sphere_points = point_matrix(
    SVector(x, y, sqrt(1 - x^2 - y^2))
        for x in range(-0.2, 0.2; length = 5), y in range(-0.2, 0.2; length = 5)
)
current_points = lattice(box, (0.1, 0.5, 0.9))
current_values = point_matrix(current_density(pinch, p) for p in eachrow(current_points))
cases = (
    (;
        name = "Open loop", truth = p -> solve(BiotSavart(), coil, p),
        domain = box, scale = 1.2, constraints = (;), exterior = false,
    ),
    (;
        name = "Conducting wall",
        truth = p -> solve(BiotSavart(ConductingWall(3, 0.0)), wire, p),
        domain = wall_box, scale = 0.8, exterior = false,
        constraints = (;
            boundary_positions = wall_points,
            boundary_normals = repeat([0.0 0.0 1.0], size(wall_points, 1)),
            boundary_values = zeros(size(wall_points, 1)),
        ),
    ),
    (;
        name = "Sphere exterior", truth = p -> background(p) + image(p),
        domain = sphere_box, scale = 0.8, exterior = true,
        constraints = (;
            reference_field = background,
            boundary_positions = sphere_points, boundary_normals = sphere_points,
            boundary_values = zeros(size(sphere_points, 1)),
            boundary_uncertainties = fill(1.0e-6, size(sphere_points, 1)),
        ),
    ),
    (;
        name = "Volume current", truth = pinch,
        domain = box, scale = 1.2, exterior = false,
        constraints = (;
            current_positions = current_points, current_density = current_values,
            current_uncertainties = fill(1.0, size(current_values)),
        ),
    ),
)

All source currents are 10 kA; distances are in metres and the sphere radius is 1 m in a 10 mT background. The Z-pinch radius is 2 m, so the entire fitted box is inside the distributed-current region, away from the discontinuous edge. There is no default current-free assumption. In particular, field-energy regularization is not a substitute for current measurements.

Fit and validate off the probe grid ​

julia
results = map(cases) do problem
    positions = lattice(problem.domain, (0.05, 0.35, 0.65, 0.95))
    heldout = lattice(problem.domain, (0.17, 0.53, 0.81))
    if problem.exterior
        positions = positions[[norm(p) > 1.02 for p in eachrow(positions)], :]
        heldout = heldout[[norm(p) > 1.02 for p in eachrow(heldout)], :]
    end
    observed = sample_field(problem.truth, positions)
    fitted = reconstruct_field_3d(
        positions, observed;
        domain = problem.domain, length_scale = problem.scale, kernel = :gaussian,
        basis_centers = lattice(problem.domain, range(0, 1; length = 4)),
        uncertainties = fill(1.0e-5, size(observed)),
        regularization = 1.0e-8, regularization_grid = (5, 5, 5),
        abstol = 1.0e-13, reltol = 1.0e-13, problem.constraints...
    )
    expected = sample_field(problem.truth, heldout)
    error = norm(sample_field(fitted, heldout) - expected) / norm(expected)
    @assert error < (problem.exterior ? 0.05 : 0.03)
    (; problem, fitted, error, probes = size(positions, 1), heldout)
end

rows = [
    "| $(r.problem.name) | $(r.probes) | $(round(100r.error; digits = 2))% |"
        for r in results
]

These are noiseless synthetic values, weighted with finite uncertainty scales to specify their relative influence; the scales are not estimated error bars. The tilted-coil demo separately includes noise and missing components. The error above is the aggregate vector norm  , not magnitude-only error or a pointwise relative error near a magnetic null.

wall_error = maximum(

Exact wall samples do not enforce zero normal field between samples. Similarly, the soft cap samples do not impose a global spherical boundary condition. The held-out checks measure these limitations explicitly.

Compare fields and errors ​

Top panels show the true field magnitude in the   slice. Bottom panels show vector error on the same slice, with separate color scales in microtesla. White regions in the sphere panels are masked physical interior, not zero error.

julia
fig_cases = Figure(; size = (1500, 780), fontsize = 16)
for (column, result) in enumerate(results)
    problem, fitted = result.problem, result.fitted
    xs = range(problem.domain[1], problem.domain[2]; length = 41)
    zs = range(problem.domain[5], problem.domain[6]; length = 41)
    magnitude = [
        problem.exterior && hypot(x, z) < 1 ? NaN :
            1.0e3 * norm(problem.truth(SVector(x, 0.0, z))) for x in xs, z in zs
    ]
    error = [
        problem.exterior && hypot(x, z) < 1 ? NaN :
            1.0e6 * norm(fitted(SVector(x, 0.0, z)) -
                problem.truth(SVector(x, 0.0, z))) for x in xs, z in zs
    ]
    for (row, values, title, units) in (
            (1, magnitude, problem.name, "|B| [mT]"),
            (2, error, "Held-out slice error", "|Bfit - B| [uT]"),
        )
        ax = Axis(
            fig_cases[row, 2column - 1]; title, xlabel = "x [m]", ylabel = "z [m]",
            aspect = DataAspect()
        )
        image_plot = heatmap!(ax, xs, zs, values; colormap = :viridis)
        Colorbar(fig_cases[row, 2column], image_plot; label = units)
        if problem.exterior
            lines!(ax, xs, sqrt.(1 .- xs.^2); color = :white, linewidth = 2)
        elseif column == 2
            hlines!(ax, [0.0]; color = :white, linewidth = 2)
        end
    end
end

Accuracy versus computational cost ​

The standalone sweep benchmark/reconstruction_scaling.jl varies kernel, center count, probe count, length scale and regularization, reporting accuracy alongside fit/evaluation time and allocations. See performance guidance.

On the external-coil sweep with deterministic 10 microtesla noise, increasing Gaussian centers from 64 to 125 at 125 probes and scale 1.2 m changed held-out field error only from about 1.74% to 1.73%, while roughly doubling fit cost. For that same 64-center fit the dimensionless spurious-curl measure was about 0.18: good field agreement does not imply equally accurate currents. Compact Wendland fits with the same data could be much worse despite full sampled support coverage. A few dozen probes cannot resolve arbitrary local current structure. These results are problem-specific, not a universal ranking of kernels.

The optimized evaluator sums basis contributions directly, and fitting assembles sparse matrices from triplets instead of repeatedly concatenating sparse rows. For a warmed, noiseless 27-probe coil fit, support scale 1.2 m and a 5-by-5-by-5 regularization grid, representative before/after measurements on Windows, Julia 1.13.1, one thread, were:

Direct summation is regression-tested against the sparse operators for both kernels, including centers, support edges and box boundaries.
