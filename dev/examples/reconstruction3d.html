3D Magnetic Field Reconstruction ​

Reconstruct a continuous magnetic field inside a box from 36 vector probes and 54 normal-boundary samples. A tilted, displaced external coil provides the synthetic truth. The reconstruction receives measurements, not the coil geometry or its analytical field.

The fitted representation is

so the field is divergence-free by construction. Sparse observations still do not uniquely determine it: the basis and regularization select a smooth solution. Boundary measurements below are uncertain observations, not exact wall conditions.

For other source terms and physical boundaries, see Reconstruction Across Sources and Boundaries. The inverse-method comparison explains how this general 3D model differs from axisymmetric flux reconstruction.

Selected magnetic field ​

julia
using Magnetostatics, StaticArrays, LinearAlgebra
using CairoMakie, FieldTracer

domain = (-0.5, 0.5, -0.5, 0.5, -0.5, 0.5)
coil = CurrentLoop(
    1.0, 1.0e4, SVector(0.2, -0.1, 2.0), normalize(SVector(0.3, 0.2, 1.0))
)
truth = CurrentLoopAnalytic(coil)

Synthetic measurements ​

julia
points_to_matrix(points) =
    reduce(vcat, [reshape(collect(p), 1, 3) for p in points])
sample_field(field, positions) =
    points_to_matrix([field(SVector{3}(p)) for p in eachrow(positions)])

function box_surface(coordinates)
    points = SVector{3, Float64}[]
    normals = SVector{3, Float64}[]
    for axis in 1:3, side in (-0.5, 0.5), a in coordinates, b in coordinates
        other_axes = filter(!=(axis), 1:3)
        point = zeros(3)
        point[axis] = side
        point[other_axes] .= (a, b)
        push!(points, SVector{3}(point))
        push!(normals, SVector{3}(ntuple(k -> k == axis ? sign(side) : 0.0, 3)))
    end
    return points, normals
end

probe_positions = points_to_matrix(Iterators.product(
    (-0.45, -0.15, 0.15, 0.45), (-0.4, 0.0, 0.4), (-0.4, 0.0, 0.4)
))
probe_sigma = 1.0e-5
probe_B = sample_field(truth, probe_positions)
probe_B .+= probe_sigma .* reshape(sin.(1:length(probe_B)), size(probe_B))
probe_B[1, 2] = NaN
probe_B[12, 3] = NaN

boundary_points, boundary_directions = box_surface((-0.35, 0.0, 0.35))
boundary_positions = points_to_matrix(boundary_points)
boundary_normals = points_to_matrix(boundary_directions)
boundary_sigma = 2.0e-5
boundary_values = [
    dot(n, truth(p)) + boundary_sigma * cos(i)
        for (i, (p, n)) in enumerate(zip(boundary_points, boundary_directions))
]

println("Vector probes: ", size(probe_positions, 1))
println("Available probe components: ", count(isfinite, probe_B))
println("Normal-boundary samples: ", length(boundary_values))
Vector probes: 36
Available probe components: 106
Normal-boundary samples: 54

Noise is deterministic to make the figures reproducible; its amplitude is set by the supplied uncertainty scale. Two missing components demonstrate partial probe measurements. In an experiment, use calibrated noise estimates and actual boundary diagnostics rather than values generated from a known model.

Fit the field ​

julia
basis_centers = points_to_matrix(Iterators.product(
    ntuple(_ -> range(-0.5, 0.5; length = 4), 3)...
))
reconstructed = reconstruct_field_3d(
    probe_positions, probe_B;
    domain, length_scale = 1.2, basis_centers, kernel = :gaussian,
    uncertainties = fill(probe_sigma, size(probe_B)),
    boundary_positions, boundary_normals, boundary_values,
    boundary_uncertainties = fill(boundary_sigma, length(boundary_values)),
    regularization = 1.0e-8, regularization_grid = (7, 7, 7),
    abstol = 1.0e-12, reltol = 1.0e-12
)
reconstructed.diagnostics
(weighted_rms = 0.5634173279745143, probe_rms = 4.795381575955523e-6, directional_rms = nothing, boundary_rms = 1.3988044669792829e-5, current_rms = nothing, exact_boundary_max_error = 0.0, exact_constraint_count = 0, coefficient_count = 195, observation_count = 160, solver_retcode = SciMLBase.ReturnCode.Success, iterations = 182, unsupported_observations = 0, unsupported_grid_points = 0, grid_point_count = 343, sampled_support_fraction = 1.0)

The global Gaussian basis is appropriate for this smooth external-coil field. The default compact Wendland basis is useful for localized structure, but needs support throughout the region of interest. Regularization penalizes correction field and curl energy; it does not impose zero current exactly.

Three-dimensional comparison ​

The left panel overlays analytical (solid blue) and reconstructed (dashed orange) field lines traced from the same six seeds. Arrows indicate the direction of the analytical field; gray markers locate the probes. These are magnetic field lines, not particle trajectories. Nearly overlapping curves indicate agreement, so a second panel explicitly shows the vector error at held-out volume locations in microtesla. Both panels use the same camera and box limits.

FieldTracer.jl traces   in both directions with native fixed-step RK4. Its domain predicate is checked before every field evaluation, including intermediate stages, so the reconstruction is never evaluated outside its box. A step crossing the boundary is discarded: endpoints remain inside, within one step of the boundary, rather than being clipped onto it. We check termination explicitly so invalid fields or exhausted step limits cannot silently produce incomplete curves.

julia
function trace_field_line(field, seed, box; ds = 0.01)
    isoutside(p, s) = any(p[k] < box[2k - 1] || p[k] > box[2k] for k in 1:3)
    result = trace(
        (p, s) -> field(p), collect(seed); ds, max_length = 4.0, isoutside
    )
    for branch in (result.backward, result.forward)
        branch.status == :outside || error("Unexpected tracing status: $(branch.status)")
    end
    return vcat(reverse(result.backward.points), result.forward.points[2:end])
end

The geometry panel intentionally does not amplify differences: the reconstructed curves should nearly coincide with the analytical ones. The error panel makes those small differences measurable without implying different field topology. Field-line endpoints are also compared when the tracing step is halved. Since FieldTracer does not locate boundary intersections, their separation is checked against the sum of the coarse and fine step lengths (0.015 m), not a boundary-event tolerance. Reduce ds for finer endpoint resolution; tracing accuracy is separate from reconstruction accuracy.

Magnitude and error on a slice ​

Compare at   m, which does not coincide with a probe plane. All three panels use millitesla (mT). The error panel measures  , not just the difference in field magnitudes. For scale, an error of 0.01 mT is 10 microtesla.

Held-out validation ​

Evaluate an independent volume grid and a new set of face locations. Neither is passed to the fit. A finite-difference divergence check verifies the analytic construction numerically; its residual depends on the differencing step.

julia
heldout_positions = points_to_matrix(Iterators.product(
    (-0.37, 0.11, 0.39), (-0.31, 0.17), (-0.23, 0.29)
))
heldout_truth = sample_field(truth, heldout_positions)
heldout_fit = sample_field(reconstructed, heldout_positions)
relative_error = norm(heldout_fit - heldout_truth) / norm(heldout_truth)
heldout_surface, heldout_normals = box_surface((-0.23, 0.21))
heldout_boundary_error = maximum(
    abs(dot(n, reconstructed(p) - truth(p)))
        for (p, n) in zip(heldout_surface, heldout_normals)
)
function numerical_divergence(field, p; h = 1.0e-5)
    return sum(1:3) do k
        step = SVector{3}(ntuple(j -> j == k ? h : 0.0, 3))
        (field(p + step)[k] - field(p - step)[k]) / (2h)
    end
end
maximum_divergence = maximum(
    abs(numerical_divergence(reconstructed, SVector{3}(p)))
        for p in eachrow(heldout_positions)
)
println("Held-out relative vector error: ", round(100relative_error; digits = 2), "%")
println("Held-out normal-boundary error [uT]: ",
    round(1.0e6 * heldout_boundary_error; digits = 2))
println("Maximum numerical |div B| [T/m]: ", maximum_divergence)
println("Weighted observation RMS: ", reconstructed.diagnostics.weighted_rms)

@assert relative_error < 0.03
@assert heldout_boundary_error < 1.0e-4
@assert maximum_divergence < 1.0e-8
Held-out relative vector error: 1.37%

Maximum numerical |div B| [T/m]: 1.938011383317839e-12

The held-out error is a synthetic benchmark, not a guarantee for experimental data. Repeat the fit with different basis resolutions, length scales, and regularization strengths to assess sensitivity. Noisy normal-boundary data need not have exactly zero integrated flux; weighted constraints accommodate this without relaxing the divergence-free representation. Residuals and sampled support coverage are not posterior uncertainty estimates.
