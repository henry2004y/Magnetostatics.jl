FLARE Experiment Reconnection Coils ​

This example combines forward coil fields with axisymmetric probe reconstruction. The forward model provides synthetic truth; the inverse fits use only the specified measurements and basis assumptions.

The Facility for Laboratory Reconnection Experiments (FLARE) at the Princeton Plasma Physics Laboratory (PPPL) is a user facility designed to study magnetic reconnection in the high-Lundquist-number ( ), multi-island regime bridging laboratory and space/astrophysical plasmas.

FLARE scales up the cylindrical flux-core reconnection concept established by the Magnetic Reconnection Experiment (MRX):

  • Flux Cores: Two toroidally symmetric flux cores positioned at major radius   m and axial separation    m. Each flux core contains internal Poloidal Field (PF) coils.

  • Equilibrium Field (EF) Coils: External coils positioned at   m and    m that supply a vertical field to position the reconnection X-line and balance the plasma hoop force.

  • Plasma Current Sheet: In driven reconnection, inductive flux transfer drives a midplane plasma current sheet () around   m, forming a macroscopic reconnection layer.

  • Guide Field: An optional out-of-plane toroidal field can be applied for guide-field / component reconnection studies.

In-Plane Field Lines and Reconnecting Field B_R ​

In the poloidal plane, the reconnecting magnetic field is primarily the radial component , which has opposite signs across the midplane  . The poloidal magnetic flux function   defines the in-plane magnetic field lines as its contours, with the separatrix passing directly through the reconnection X-point null.

julia
# Helper to locate the midplane X-point null
function find_xpoint(fl; Rmin=0.5, Rmax=1.3, N=2000)
    Rs = range(Rmin, Rmax, length=N)
    Bzs = [fl(SVector(R, 0.0, 0.0))[3] for R in Rs]
    for i in 1:(N-1)
        if Bzs[i] * Bzs[i+1] <= 0
            return Rs[i] - Bzs[i] * (Rs[i+1] - Rs[i]) / (Bzs[i+1] - Bzs[i])
        end
    end
    return NaN
end

Reconstructing from Sparse Probe Measurements ​

An axisymmetric field can be reconstructed from sparse measurements of the cylindrical components in the poloidal plane. The poloidal field is represented by the flux function , so its divergence-free condition is satisfied by construction, and the toroidal current density follows from the Grad-Shafranov operator,   .

To test both the field and the current recovery, the reference field combines the FLARE coils with a distributed 15 kA toroidal current sheet between the flux cores,

with   m,   m and   m. The sheet is discretized into coaxial loops with Gaussian cores of width   cm. Each core adds the exact two-dimensional correction to the loop field, so is smooth and    holds to high accuracy.

julia
struct GaussianCoreSheet
    loops::Vector{CurrentLoop{Float64}}
    σ::Float64
end

function GaussianCoreSheet(; Rc, a, δ, Ip, h=0.01, σ=0.01)
    # The offset keeps the cores away from the regular evaluation grids
    nodes = [(R + 0.00317, Z + 0.00213) for R in (Rc - 3a):h:(Rc + 3a)
                                         for Z in -4δ:h:4δ]
    w = [exp(-((R - Rc) / a)^2) * sech(Z / δ)^2 for (R, Z) in nodes]
    loops = [CurrentLoop(R, Ip * wk / sum(w), SVector(0.0, 0.0, Z),
                 SVector(0.0, 0.0, 1.0)) for ((R, Z), wk) in zip(nodes, w)]
    return GaussianCoreSheet(loops, σ)
end

function (s::GaussianCoreSheet)(p)
    R = hypot(p[1], p[2])
    B = zero(SVector{3, Float64})
    for loop in s.loops
        B += getB_loop(p, loop)
        dR, dZ = R - loop.radius, p[3] - loop.center[3]
        d2 = dR^2 + dZ^2
        c = -Magnetostatics.μ₀ * loop.current * exp(-d2 / (2s.σ^2)) / (2π * d2)
        B += SVector(c * dZ * p[1] / R, c * dZ * p[2] / R, -c * dR)
    end
    return B
end

function toroidal_current(s::GaussianCoreSheet, R, Z)
    return sum(s.loops) do loop
        d2 = (R - loop.radius)^2 + (Z - loop.center[3])^2
        loop.current * exp(-d2 / (2s.σ^2))
    end / (2π * s.σ^2)
end

sheet = GaussianCoreSheet(; Rc=0.95, a=0.15, δ=0.05, Ip=15.0e3)
reference(p) = flare(p) + sheet(p)

We sample this field with magnetic probes and add small deterministic errors to create synthetic measurements. In an experiment, replace these samples with calibrated measurements and their uncertainties. A few modeling choices are essential for an accurate reconstruction:

  • Exclude the sources. The PF filaments at   m are singular, so the reconstruction domain covers only the plasma region between the flux cores, where probes can actually be placed.

  • Represent the external coil field. Virtual current filaments placed outside the domain (filament_positions) give exact current-free solutions inside it and capture the steep field near the flux cores. Their currents are fit to the data, so neither the coil currents nor their positions are assumed.

  • Represent the plasma current. A bump in with compact support, such as the default :wendland_c2 radial basis function, carries no net toroidal current, since    around its support. We compare two remedies:

    1. Gaussian kernel (kernel = :gaussian) with a 6 cm length scale. Its wide tails can place the return current of each bump outside the domain, but every basis function touches every probe, so the linear system is dense.

    2. Current elements (current_element_positions) on a 5 cm grid, combined with the default sparse Wendland basis. Each element is a coaxial loop with a smooth core, so it carries net current and the sum of the fitted element currents estimates the plasma current.

  • Regularize the current. Imposing   at collocation points with a loose uncertainty of A/m² (below the A/m² peak) selects the smallest current distribution consistent with the probes. A much tighter uncertainty would instead enforce a vacuum field.

julia
using LinearSolve: QRFactorization

Rmin, Rmax = 0.45, 1.25
Zmin, Zmax = -0.28, 0.28
rz_matrix(points) = reduce(vcat, [[R Z] for (R, Z) in points])
grid_rz(h) = [(R, Z) for R in Rmin:h:Rmax for Z in Zmin:h:Zmax]

function synthetic_probes(probe_rz)
    B = reduce(vcat, [
        permutedims(collect(reference(SVector(R, 0.0, Z)))) for (R, Z) in probe_rz
    ])
    for i in axes(B, 1)
        B[i, 1] += 2.0e-4 * sin(i)
        B[i, 2] += 2.0e-4 * cos(i)
        B[i, 3] += 2.0e-4 * sin(2i)
    end
    return B
end

# Virtual filaments evenly spaced on a rectangle 0.1 m outside the domain
function rectangle_points(r0, r1, z0, z1, n)
    corners = [(r0, z0), (r1, z0), (r1, z1), (r0, z1), (r0, z0)]
    sides = [hypot(b[1] - a[1], b[2] - a[2])
             for (a, b) in zip(corners[1:end-1], corners[2:end])]
    ends = cumsum(sides)
    return map(range(0, ends[end]; length=n + 1)[1:end-1]) do s
        k = findfirst(>(s), ends)
        t = 1 - (ends[k] - s) / sides[k]
        a, b = corners[k], corners[k + 1]
        (a[1] + t * (b[1] - a[1]), a[2] + t * (b[2] - a[2]))
    end
end
filament_rz = rectangle_points(Rmin - 0.1, Rmax + 0.1, Zmin - 0.1, Zmax + 0.1, 48)
element_rz = grid_rz(0.05)
collocation_rz = grid_rz(0.015)

function reconstruct(probe_rz, method)
    basis = if method === :gaussian
        (; kernel=:gaussian, length_scale=0.06,
            basis_centers=rz_matrix(grid_rz(0.03)))
    else
        (; length_scale=0.12, basis_centers=rz_matrix(grid_rz(0.06)),
            current_element_positions=rz_matrix(element_rz))
    end
    probe_B = synthetic_probes(probe_rz)
    return reconstruct_axisymmetric_field(
        rz_matrix(probe_rz), probe_B;
        domain = (Rmin, Rmax, Zmin, Zmax),
        basis...,
        regularization = 1.0e2,
        uncertainties = fill(5.0e-4, size(probe_B)),
        filament_positions = rz_matrix(filament_rz),
        current_positions = rz_matrix(collocation_rz),
        current_density = zeros(length(collocation_rz)),
        current_uncertainties = fill(1.0e5, length(collocation_rz)),
        algorithm = QRFactorization()
    )
end

    Colorbar(fig[2, 4]; limits=(0, Bp_max), colormap=:cividis, label=Bp_label)
    Colorbar(fig[3, 4]; limits=(0, 0.05), colormap=:inferno, label="Relative error")
    Colorbar(fig[4, 4]; limits=(-J_max, J_max), colormap=:balance, label=J_label)
    colsize!(fig.layout, 1, Auto(1)); colsize!(fig.layout, 2, Auto(1))
    colsize!(fig.layout, 3, Auto(1))
    rowgap!(fig.layout, 1, 8)
    return fig
end

Uniform Probe Array ​

We first sample the field on a uniform   probe array.

julia
uniform_rz = [(R, Z) for R in range(0.48, 1.22; length=12)
                      for Z in range(-0.25, 0.25; length=11)]
gaussian_fit = reconstruct(uniform_rz, :gaussian)
element_fit = reconstruct(uniform_rz, :elements)
println("Sum of fitted element currents: ",
    round(sum(element_fit.element_currents) / 1e3, digits=2), " kA")
fig4 = compare_reconstructions(uniform_rz, [
    "Gaussian RBF" => gaussian_fit,
    "Wendland RBF + current elements" => element_fit
])

Both methods recover the magnetic field to about a percent and the total current to within a few tenths of a kiloampere. The largest field errors lie inside the sheet, where reverses over a few centimeters between probe rows. The current density is never measured, yet its location, shape and total are recovered from the field alone; its peak is smoothed by the minimum-current regularization and the finite probe spacing. The Gaussian kernel gives a slightly smoother current, while current elements keep the default sparse Wendland basis and report the plasma current directly through element_currents.

Non-Uniform Probe Coverage ​

Probe access is rarely uniform in an experiment. Here, the upper half of the domain keeps a dense   array, while the lower half has only three rows of six probes. The reconstruction does not assume the up-down symmetry of the reference field, so the poorly sampled half must be inferred from fewer data.

julia
upper_rz = [(R, Z) for R in range(0.48, 1.22; length=12)
                    for Z in range(0.0, 0.25; length=8)]
lower_rz = [(R, Z) for R in range(0.48, 1.22; length=6)
                    for Z in range(-0.25, -0.25 / 3; length=3)]
nonuniform_rz = vcat(upper_rz, lower_rz)
fig5 = compare_reconstructions(nonuniform_rz, [
    "Gaussian RBF" => reconstruct(nonuniform_rz, :gaussian),
    "Wendland RBF + current elements" => reconstruct(nonuniform_rz, :elements)
])

The upper half is reconstructed as accurately as with the uniform array. The error grows to several percent in the sparsely sampled lower half, concentrated in the gap between the midplane and the first lower probe row, where the lower part of the current sheet is not bracketed by measurements, and along the bottom edge between the widely spaced probes. The vertical profile shows that the recovered current sheet becomes asymmetric: it stays sharp on the well-sampled side but is smeared toward the sparsely sampled side, and the total current drops by about 2%. Both methods degrade in the same way, so the probe coverage, not the basis, limits the accuracy here.
