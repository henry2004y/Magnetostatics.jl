Empirical Magnetosphere Models ​

This example demonstrates how to build an advanced, data-based empirical model of the Earth's magnetosphere by combining the internal planetary magnetic field with external empirical field models. We will utilize the PlanetaryMagneticFields.jl package for an accurate representation of the Earth's internal field (IGRF) and TsyganenkoModels.jl for the external currents (T96 model). GeoCotrans.jl is used to accurately perform coordinate transformations between Geographic (GEO) and Geocentric Solar Magnetospheric (GSM) coordinate systems.

Model Formulation ​

The total magnetic field vector at any point in the magnetosphere is the superposition of the internal main field generated by the geodynamo and the external field produced by various current systems (magnetopause currents, ring current, cross-tail current, and field-aligned currents):

1. Internal Field: IGRF ​

The International Geomagnetic Reference Field (IGRF) is a standard mathematical description of the Earth's main magnetic field and its secular variation. PlanetaryMagneticFields.jl provides access to these models using spherical harmonic expansions. Since IGRF is naturally expressed in Geographic (GEO) coordinates, we must transform the queried position from GSM to GEO, evaluate the internal field, and then transform the resulting field vector back to GSM.

2. External Field: T96 Model ​

The Tsyganenko 1996 (T96) model is an empirical model of the Earth's magnetospheric magnetic field. It is parameterized by solar wind conditions and the Dst index. The model operates in Geocentric Solar Magnetospheric (GSM) coordinates, where the X-axis points towards the Sun, and the X-Z plane contains the Earth's magnetic dipole axis.

Implementation ​

julia
using PlanetaryMagneticFields
using TsyganenkoModels
using GeoCotrans
using Dates
using StaticArrays, LinearAlgebra
using CairoMakie, UniformStreamlines, GeometryBasics

# 1. Define the parameters for the T96 empirical model
# Typical solar wind conditions
pdyn = 2.0     # Solar wind dynamic pressure [nPa]
dst = -20.0    # Dst index [nT] (moderate activity)
byimf = 2.0    # IMF By component [nT]
bzimf = -2.0   # IMF Bz component [nT] (southward IMF)

# Create the T96 external field model
t96 = T96(; pdyn, dst, byimf, bzimf)

# 2. Define the Internal Field Model (IGRF 2020)
igrf = load_model(:earth, "igrf2020")

# 3. Time of Evaluation
# The coordinate transformation between GEO and GSM depends on the current time
# Let's pick a time near the Northern Summer Solstice to see a large dipole tilt
t = DateTime("2020-06-21T12:00:00")

# Calculate the dipole tilt angle required by the Tsyganenko model
# The dipole tilt is the angle between the Earth's magnetic dipole axis and the Z-axis of GSM.
ps = dipole_tilt(t)

# 4. Define the Composite Magnetic Field Function
function empirical_B_field(r_gsm::AbstractVector)
    # Evaluate External Field (T96)
    # T96 model expects GSM coordinates and the dipole tilt angle `ps`
    B_ext = t96(r_gsm, ps)

    # Evaluate Internal Field (IGRF)
    # IGRF expects Geographic (GEO) coordinates
    # Convert position from GSM to GEO
    r_geo = gsm2geo(r_gsm, t)

    # Evaluate the internal field using PlanetaryMagneticFields.jl
    # The model takes a Cartesian position vector (in GEO) and returns Cartesian field
    B_int_geo = igrf(r_geo; from=:cartesian, to=:cartesian)

    # Convert the internal magnetic field vector back from GEO to GSM
    B_int_gsm = geo2gsm(B_int_geo, t)

    # Total Field is the superposition
    return SVector{3}(B_int_gsm) + SVector{3}(B_ext)
end

# Test the function at 5 RE on the nightside (GSM X = -5)
r_test = SVector(-5.0, 0.0, 0.0)
B = empirical_B_field(r_test)
println("B at $r_test in GSM: $B [nT]")
B at [-5.0, 0.0, 0.0] in GSM: [-267.06341823938766, -4.19919839608961, 179.3519213698394] [nT]

Visualization in the X-Z GSM Plane ​

We can visualize the resulting magnetic topology. Since Tsyganenko models contain open boundary conditions (the magnetopause is often defined geometrically), we'll define a boundary to stop streamlines from venturing outside the modeled domain.

julia
# Define the X-Z grid
xs = range(-30, 15, length=100)
zs = range(-20, 20, length=100)

# Create a helper function to get only X and Z components of B for the 2D streamplot
function get_B_xz(x, z)
    r = SVector(x, 0.0, z)
    B = empirical_B_field(r)
    return SA[B[1], B[3]]
end

# Evaluate B magnitude on the grid
Bmag = [norm(empirical_B_field(SVector(x, 0.0, z))) for x in xs, z in zs]

# Setup plot
fig = Figure(size = (900, 700), fontsize=20)
ax = Axis(fig[1, 1],
    xlabel=L"X_{GSM} [$R_E$]", ylabel=L"Z_{GSM} [$R_E$]",
    title="T96 + IGRF Earth Magnetosphere Model",
    aspect=DataAspect())

# Plot background field magnitude (log scale)
hm = heatmap!(ax, xs, zs, log10.(Bmag .+ 1.0),
    colormap=:turbo, colorrange=(0, 5))
Colorbar(fig[1, 2], hm, label=L"$\log_{10}$(|B| [nT])")

# Add streamlines
# Note: Streamlines may look jagged near the inner region due to the strong 1/r^3 dipole
str = evenstream(xs, zs, get_B_xz; min_density=1.5, max_density=3.0)
streamlines!(ax, str; color = :black, linewidth = 1.0, with_arrows = true)

# Plot Earth body
poly!(ax, Circle(Point2f(0, 0), 1.0), color=:gray)

limits!(ax, -30, 15, -20, 20)
fig

This visualization showcases the combined effect of the Earth's tilted internal dipole field embedded within the solar-wind driven external current systems. Unlike the simple analytical models, the nightside tail field here strongly depends on the specific IMF conditions and dynamic pressure provided to the T96 model.
